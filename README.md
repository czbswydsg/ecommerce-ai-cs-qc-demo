# 电商 AI 客服质检台 · MVP Demo

一个面向电商 AI 客服场景的质量评测与持续优化工作台，重点解决 AI 客服回答中的“错在哪里、为什么错、风险多大、依据是什么、怎么修、修完是否有效”等问题。

> 当前为作品集 Demo，仅含 10 条模拟示例数据，纯前端实现，无后端依赖。
