一个用于评估电商 AI 客服回答质量的质检工具原型。

## 功能说明

### 1. 裁定书式质检

一条 Case 打开后，一屏看到：

- 综合得分与结论
- 风险等级（独立于总分）
- 核心问题一句话
- 待检对话（用户问题 + AI 回答）
- 官方判定依据（四层证据）
- 六项独立评分
- Badcase 归因
- 优化建议与回归状态
- 参考答案对照

### 2. 六项评分指标

| 指标 | 说明 |
|---|---|
| 分类准确 | 是否理解用户核心诉求，回答方向是否正确 |
| 风险判断 | 是否识别业务风险，是否轻率下结论 |
| 证据引用 | 核心结论是否有官方依据支持 |
| 边界合规 | 是否存在越权、虚假承诺、绝对化表述 |
| 人工转接 | 是否需要人工介入，时机与路径是否合理 |
| 问题解决 | 用户能否据回答继续完成目标 |

每项 0～2 分，总分 12 分。

- 10～12 分：通过
- 7～9 分：需优化
- 0～6 分：不通过

### 3. 风险与总分独立

低分不等于高风险，高分也不等于无风险。  
高风险 Case 必须重点核查「风险判断」「边界合规」「人工转接」三项。

### 4. Badcase 归因

支持多选，覆盖：

- 规则错误
- 虚假承诺
- 越权承诺
- 无依据生成
- 证据不足
- 风险识别不足
- 人工转接不合理
- 问题未解决
- 信息遗漏
- 分类错误

### 5. 证据四层来源

- 商品层：商品详情页 / SKU 参数
- 订单层：订单 / 支付 / 物流 / 售后页
- 规则层：官方规则与活动规则页
- 流程层：官方 SOP 与客服流程

## 评测标准摘要

### 评分原则

- 六项指标独立打分，不相互带动。
- 证据不足 ≠ 无依据生成：缺少 SKU / 订单等必要信息只标「证据不足」；仅当官方公开信息能证明结论错误时才标「无依据生成」。
- 出现“以页面为准”不自动得 2 分，须判断其前面的核心结论本身是否有官方依据。
- 风险等级只表示业务风险程度，不由总分决定。

### 评测依据优先级

京东官方商品 / 订单页面 ＞ 官方帮助中心 ＞ 售后 / 价保 / 物流等业务页面 ＞ 平台规则 ＞ 其他官方公开信息。

不得以淘宝、拼多多、抖音电商等其他平台规则替代。
